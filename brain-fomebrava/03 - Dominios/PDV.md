# PDV

Formato atual:
```text
/[tenant]/pdv/[token]
```

O link pode ser protegido por senha.

```text
operador acessa link → informa senha → seleciona produtos → registra pagamento → cria pedido → pedido entra na cozinha
```

Meios presenciais observados: dinheiro e PIX.
