# Precificação Solidária

Pode considerar:
- ingredientes;
- embalagens;
- custos de produtos;
- custos operacionais;
- despesas compartilhadas;
- reserva para perdas;
- referência regional;
- meta de arrecadação.

Objetivo:
```text
acessibilidade + cobertura de custos + sustentabilidade financeira
```
