# Cozinha KDS

Kitchen Display System com colunas:
```text
Recebido → Fazendo → Pronto → Entregue
```

Objetivos de UX:
- leitura rápida;
- poucos cliques;
- atualização imediata;
- identificação clara do código;
- identificação clara dos itens.

Usa [[Realtime]].
