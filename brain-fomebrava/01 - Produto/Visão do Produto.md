# Visão do Produto

O Fomebrava centraliza o ciclo de venda de alimentos:

```text
planejar → cadastrar produtos → vender → receber pagamento → produzir → entregar → acompanhar resultados
```

## Problemas que busca reduzir
- comandas físicas;
- comunicação verbal entre caixa e cozinha;
- conferência manual de pagamentos;
- planilhas paralelas;
- sistemas desconectados.

## Direção
O projeto evoluiu de uma operação específica para uma plataforma com características de SaaS. Ver [[Multi-tenant]].
